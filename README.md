# 結屋 2026年9月 プライズ景品 入荷情報ポータル（新世界店・大和郡山店）

ゲームセンター「結屋」新世界店（152件）および大和郡山店（248件）の2026年9月メーカー景品入荷予定表と、メーカー公式高解像度写真を紐付けたWebカタログアプリケーションです。

## 🌐 公開URL (GitHub Pages)
https://jamaisvu0404.github.io/musubiya-prize/

## 🎯 主な機能
- **店舗切り替え**: 新世界店、大和郡山店、全店舗の統合比較
- **大和郡山店参考の納期自動補完**: 新世界店で「未定」となっている景品（47件）を大和郡山店の入荷予定日を参考にしてカレンダーに統合表示
- **メーカー公式写真紐付け**: バンプレスト、セガ、フリュー、タイトー（雪ミク・着せ恋など）の公式写真を表示
- **3つのビューモード**: 📅 日付タイムライン / 🖼️ ギャラリー / 📋 一覧リスト表
- **メルカリ相場連携**: 各景品ワンクリックで市場相場を即時検索
- **元の入荷予定表ビューア**: X公式投稿画像（全7枚）を閲覧可能
- **完全ライトモードUI**: 清潔感と視認性に優れたモダンデザイン
